# 🏦 Village Bank Management System

A simple web-based banking system built using Python (Flask) to manage local village banking operations.

## 🚀 Features

- User authentication (Admin/Staff)
- Customer account management
- Deposit & withdrawal system
- Transaction history
- Loan management
- Dashboard & reports

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Database: SQLite

## 📂 Setup

1. Clone the repository
2. Create virtual environment
3. Install dependencies:
   pip install -r requirements.txt
4. Run the app:
   python app.py

## 💡 Purpose

This project is built for learning backend development and understanding real-world banking systems.
