🗄️ Database Design (6 Tables)
1. users (System Admins & Staff)
id - Primary key

username - Unique login name

password_hash - Securely hashed password

role - 'admin' or 'staff'

created_at - Timestamp


--------------------------------------------------------------------
2. customers (Core Profiles)
id - Primary key

full_name - Customer's complete name

address - Physical address

phone_number - Unique contact number

citizenship_id - Unique government ID

status - 'active' or 'inactive' (soft delete)

created_at - Registration timestamp


----------------------------------------------------------------------
3. accounts (Savings/Current Accounts)
id - Primary key

customer_id - Foreign key to customers

account_number - Unique 10-digit identifier

account_type - 'savings' or 'current'

balance - Current account balance (Decimal)

status - 'active', 'suspended', 'closed'

created_at - Account opening date

-------------------------------------------------------------------------

4. transactions (Ledger - Immutable History)
id - Primary key

transaction_uuid - Unique tracking code (TXN-XXXXXXXX)

account_id - Foreign key to accounts

type - 'deposit' or 'withdrawal'

amount - Transaction amount

balance_after - Account balance snapshot

description - Transaction memo

created_by - Operator who processed it

created_at - Timestamp


------------------------------------------------------------------------
5. loans (Borrowing Records)
id - Primary key

loan_number - Unique identifier (LNX-XXXXXX)

customer_id - Foreign key to customers

amount - Principal amount

interest_rate - Annual percentage rate

duration_months - Loan term in months

emi - Calculated monthly installment

total_payable - Principal + total interest

total_paid - Amount repaid so far

status - 'pending', 'approved', 'rejected', 'fully_paid'

applied_date - Application timestamp

approved_date - Approval timestamp

approved_by - Admin who approved

------------------------------------------------------------------------------------

6. repayments (Loan Payment History)
id - Primary key

loan_id - Foreign key to loans

amount - Payment amount

repayment_date - Payment timestamp

received_by - Operator who collected payment

🔐 Authentication & Security Features
Implemented:
Session-based authentication with Flask sessions

Password hashing using Werkzeug

Role-based access control (RBAC):

Admin: Full access, can approve loans

Staff: Can manage customers, process transactions, apply for loans (cannot approve)

@login_required decorator - Protects all routes

@role_required decorator - Restricts admin-only operations

Soft delete system - Preserves audit trails

🏦 Loan Management Module
Features:
✅ Apply for loan (staff can apply for customers)

✅ EMI calculation using reducing-balance formula

✅ Automatic fund disbursement upon approval

✅ Flexible repayment options:


----------------------------------------------------------------------------------
Cash payment

Direct debit from savings account

✅ Loan progress tracking with visual indicators

✅ Loan status: pending → approved → fully_paid

EMI Formula Used:
text
EMI = P × r × (1+r)^n / ((1+r)^n - 1)

Where:
P = Principal amount
r = Monthly interest rate (annual rate / 12 / 100)
n = Duration in months
Loan Application Fields:
Customer selection


Principal amount

Interest rate (% per annum)

Duration (months)

Auto-calculated EMI, total interest, total payable

🐛 Bugs Fixed During Development
Bug 1: Decimal + Float TypeError in Dashboard
Error: unsupported operand type(s) for +: 'decimal.Decimal' and 'float'
Fix: Converted Decimal values to float in backend and added |float filters in template

Bug 2: Transaction Deposit TypeError
Error: Same Decimal/Float mismatch in deposit route
Fix: Changed amount conversion from float() to Decimal() and used Decimal arithmetic

Bug 3: Template Formatting Issues
Error: Broken brackets and indentation in dashboard.html
Fix: Cleaned up HTML/Jinja2 syntax, fixed all closing tags
